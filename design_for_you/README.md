# Design For You

# Interior & Style 3D Configurator

> A modern, interactive 3D web application allowing users to visualize color palettes and realistic textures in real-time. Whether designing a cozy living space or styling a fresh outfit, this tool brings creativity to life.

---

## 📖 About the Project

This project is a cutting-edge 3D configuration tool built with **Vue.js** and **Three.js** (via TresJS). It features a sleek, modern UI utilizing a **Glassmorphism** design language, elegant typography, and seamless transitions.

Users can toggle between two distinct modes—**Interior Design** and **Clothing**—to experiment with curated color palettes and apply physically based rendering (PBR) textures dynamically fetched from an external API.

## ✨ Key Features

* **🎭 Dual Modes:** Switch seamlessly between "Interior Design" (room, bed, table) and "Clothing" (shirt, trousers, shoes) environments.
* **🖌️ Curated Color Palettes:** Test designs instantly with hand-picked thematic palettes:
* *Vibrant & Pop-Art*
* *Soft Pastel*
* *Deep Elegant*
* **🧱 Realistic Materials:** Integrated with the **Poly Haven API** to fetch and apply real-world, high-quality textures (wood, stone, fabrics) to 3D objects on the fly.
*   **💎 Modern UI/UX:** Features a responsive, frosted-glass sidebar (Glassmorphism), satisfying hover animations, and a full-screen interactive 3D canvas.
*   **⚡ High Performance:** Built with Vue's Composition API and optimized texture loading to ensure smooth 3D rendering in the browser.

---

## 🛠️ Tech Stack

* **Framework:** [Vue.js 3](https://vuejs.org/) (Composition API)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **3D Engine:** [Three.js](https://threejs.org/) & [TresJS](https://tresjs.org/)
* **API Integration:** [Poly Haven API](https://polyhaven.com/api) (for dynamic textures)
* **Styling:** Pure CSS (Custom variables, Backdrop-filters, Flexbox/Grid)
